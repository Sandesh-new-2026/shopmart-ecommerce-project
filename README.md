# 🛍️ E-Commerce Website

## Full-Stack E-Commerce Application

**Developed by Sandesh Bhadane**

A modern, responsive and full-stack E-Commerce web application built using **React.js, Node.js, Express.js and MongoDB**.

This project provides a complete online shopping experience including product browsing, search, filtering, authentication, shopping cart, wishlist, orders, profile management, saved addresses and account security.

---
